# omni_statanalysis_bot

Telegram-бот, который собирает статистику сообщений из указанного канала и присылает сравнительные отчёты еженедельно и ежемесячно.

## Быстрый старт

1. Python 3.11+
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Создайте файл `.env` (или отредактируйте существующий) и укажите значения:
```
TELEGRAM_BOT_TOKEN=<токен бота>
CHANNEL_ID=<id канала, например -100...>
DATABASE_PATH=data/bot.db
TIMEZONE=Europe/Moscow
WEEKLY_REPORT_HOUR=9
MONTHLY_REPORT_HOUR=9
```
4. Запустите бота:
```
python -m bot.main
```

Бот автоматически:
- сохраняет сообщения канала в SQLite;
- раз в неделю отправляет отчёт с сравнением текущей и прошлой недели;
- раз в месяц отправляет отчёт с сравнением текущего и прошлого месяца.

Команда `/stats` в личном чате с ботом — проверка, что бот активен.

## Права бота
- Добавьте бота в канал `CHANNEL_ID` и дайте право читать сообщения.
- Для публикации отчётов в канал — право отправлять сообщения.

## Структура
- `bot/config.py` — конфигурация
- `bot/db.py` — БД и агрегации
- `bot/handlers.py` — обработчики сообщений канала
- `bot/reporting.py` — генерация отчётов
- `bot/main.py` — запуск, расписание, polling
